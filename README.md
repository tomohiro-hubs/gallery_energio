# 太陽光発電所ギャラリー | Solar Power Plant Gallery

太陽光発電所の開発済発電所を美しくギャラリー表示するWebサイトです。

## ✅ 実装済み機能

### ギャラリー表示
- **16:9アスペクト比のカード型レイアウト** — 各発電所の写真を統一された比率で表示
- **発電所名・AC出力・DC出力のオーバーレイ表示** — 写真上に情報をスタイリッシュに表示
- **カテゴリバッジ** — メガソーラー / 中規模 / 小規模を色分けで即座に判別
- **ホバーエフェクト** — 画像ズーム・影の変化で直感的なインタラクション

### モーダル詳細表示
- **クリックで大画面モーダルを表示** — 発電所の詳細情報を一覧
- **表示項目**: AC出力、DC出力、パネル枚数、敷地面積、竣工日、DC/AC比
- **概要テキスト** — 各発電所の特徴や背景情報

### フィルター・検索・ソート
- **テキスト検索** — 発電所名・所在地・説明文で検索
- **カテゴリフィルター** — すべて / メガソーラー / 中規模 / 小規模
- **ソート機能** — 名前順 / AC出力（大→小, 小→大）/ 竣工日順

### ヒーロー統計 & サマリー
- **ヒーローセクション** — 総発電所数、総AC出力、総DC出力、総パネル枚数をハイライト
- **統計セクション** — カテゴリ別件数、最大AC出力、平均AC出力、総敷地面積

### レスポンシブデザイン
- **PC・タブレット・スマートフォン対応** — 全デバイスで美しい表示

## 📊 データモデル

### テーブル: `power_plants`

| フィールド | 型 | 説明 |
|-----------|------|------|
| id | text | 一意識別子 |
| name | text | 発電所名 |
| location | text | 所在地 |
| ac_output | number | AC出力（kW） |
| dc_output | number | DC出力（kW） |
| panel_count | number | パネル枚数 |
| completion_date | text | 竣工日 |
| area | number | 敷地面積（㎡） |
| image_url | text | 発電所画像URL |
| description | text | 発電所の説明 |
| category | text | カテゴリ（メガソーラー / 中規模 / 小規模） |

### API エンドポイント

| メソッド | パス | 説明 |
|---------|------|------|
| GET | `tables/power_plants` | 全発電所一覧取得 |
| GET | `tables/power_plants/{id}` | 個別発電所取得 |
| POST | `tables/power_plants` | 発電所追加 |
| PUT | `tables/power_plants/{id}` | 発電所更新 |
| DELETE | `tables/power_plants/{id}` | 発電所削除 |

## 🛠️ 使用技術

- **HTML5** / **CSS3** — セマンティクスとモダンレイアウト
- **JavaScript (ES6+)** — Fetch API によるデータ取得
- **Noto Sans JP** (Google Fonts) — 日本語フォント
- **Font Awesome 6** — アイコン
- **RESTful Table API** — データ永続化
